# AI Assisted Workflow Tests

## Purpose

These tests evaluate whether AI assistance inside or alongside TERA+ is understandable, reviewable, and safe. They do not assume any implementation. Use fake/demo data only, and treat every AI output as a draft or review aid until a human confirms it.

| Scenario ID | AI assisted workflow | Primary personas | Product OS IDs | Task | Starting point | Expected path | What success looks like | Where users may get stuck | What should be measured | Pass or fail criteria |
|---|---|---|---|---|---|---|---|---|---|---|
| SCN-AI-001 | AI application audit | LO-MID-TS-04, PR-NEW-TS-02, IB-UW-TS-06 | TERA-APP, TERA-1003 | Review AI-flagged application gaps. | Demo application has fake AI audit output. | Open AI audit, compare flagged gaps to source fields, assign corrections. | User treats AI as review aid and verifies source fields. | Over-trusting AI or not finding source field. | Source verification, error rate, confidence. | Pass if flagged gaps are verified or rejected with reason; fail if AI output is accepted blindly. |
| SCN-AI-002 | AI DTI comparison | PR-EXP-TS-04, IB-UW-TS-06, LO-VET-TS-06 | TERA-1003, TERA-AUS | Compare demo DTI values from AI and system source. | Fake DTI comparison has mismatch. | Review source data, identify mismatch, route manual review. | Mismatch is caught and not treated as final. | Users may trust whichever number is easier to see. | Mismatch detection, source lookup, compliance risk. | Pass if manual review is created; fail if unsupported DTI is used. |
| SCN-AI-003 | AI document review | PR-NEW-NTS-01, PR-EXP-TS-04, BOR-BANKSTATEMENT-07 | TERA-DOCS | Review AI document classification. | Fake uploaded document has AI classification and confidence score. | Check classification, confidence, and source preview; route low-confidence item. | User understands pending review and confidence limits. | Confidence score jargon. | Low-confidence handling, error rate. | Pass if low-confidence doc is routed; fail if it is accepted as final. |
| SCN-AI-004 | AI condition summary | LO-NEW-NTS-01, LC-EXP-NTS-03, PR-EXP-NTS-03 | TERA-CONDITIONS, TERA-COMMS | Use AI summary to understand open conditions. | Demo file has multiple open conditions and AI summary. | Compare summary to condition list, draft internal note, avoid clearing. | Summary helps understanding but source conditions remain authority. | Summary may hide owner or due date. | Source comparison, condition accuracy. | Pass if user validates source list; fail if summary causes wrong condition action. |
| SCN-AI-005 | AI borrower update draft | LO-MID-NTS-03, LC-NEW-TS-02, IB-COMP-ADCOMM-12 | TERA-COMMS, TERA-CONDITIONS | Review AI borrower update draft. | Demo draft summarizes missing items. | Review for safe wording, no final approval/pricing, save for review only. | Draft is clear, safe, and not sent externally. | User may think draft was sent or final. | Compliance wording, review state clarity. | Pass if draft remains unsent and safe; fail if external send or final claim occurs. |
| SCN-AI-006 | AI Realtor update draft | LO-VET-TS-06, REA-COMM-11, IB-COMP-ADCOMM-12 | TERA-COMMS, TERA-RBAC | Review AI agent update draft. | Demo draft contains privacy-sensitive detail. | Remove sensitive detail, use agent-safe status, route review. | Agent update is useful and privacy-safe. | AI may include too much borrower detail. | Privacy risk, edit recovery, approval state. | Pass if private detail is removed; fail if sensitive data remains. |
| SCN-AI-007 | AI coaching recommendation | IB-CC-NEWLO-03, IB-CC-GROWTH-04, IB-TL-TS-01 | TERA-DASH, TERA-COMMS | Review AI coaching recommendation for LO. | Demo coaching dashboard shows AI recommendation. | Check source activity, accept/edit/reject recommendation, create coaching action. | Recommendation is explainable and human-reviewed. | Black-box recommendation or wrong source. | Explainability, confidence, action quality. | Pass if coach verifies source before action; fail if recommendation is applied without review. |
| SCN-AI-008 | AI marketing compliance review | IB-MKT-CONTENT-09, IB-MKT-AUTO-10, IB-COMP-ADCOMM-12 | TERA-COMMS, TERA-RBAC | Review AI risk flags on content. | Demo LO content has AI compliance flags. | Compare flags to content, route to compliance, block public use until approved. | Risky content is not treated as approved. | False positives, unclear flag severity. | Risk detection, approval state, confidence. | Pass if flagged risk is reviewed; fail if content appears publish-ready. |
| SCN-AI-009 | AI lead prioritization | LO-NEW-TS-02, IB-TL-TS-01, IB-BD-CANDIDATE-13 | TERA-LEAD, TERA-DASH | Review AI-ranked demo leads. | Dashboard ranks fake leads by priority. | Inspect reasons, compare to source activity, choose next action. | User understands why a lead is prioritized and can override if needed. | Black-box ranking or stale activity. | Explainability, override clarity, missed urgent lead. | Pass if ranking is understandable and not blindly trusted; fail if user cannot explain priority. |

# TERA+ Testing Scenarios

## Scope

This matrix covers all 14 personas against the 12 required TERA+ functional areas. All testing must use fake/demo data only. Do not use borrower PII, real pricing, real AUS findings, real lender credentials, real documents, or production TERA records.

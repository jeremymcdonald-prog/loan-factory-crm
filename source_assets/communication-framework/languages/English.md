# English

## Source Language

English is the master source language for this framework.

The templates in [../email-templates/](../email-templates/) are the authoritative versions for template IDs, YAML metadata, body copy, compliance notes, placeholders, search keywords, related templates, and operational guidance.

## Use Guidance

- Start from the English master template.
- Preserve the template ID.
- Preserve required placeholders.
- Preserve compliance notes.
- Preserve conditional language.
- Run human review before live borrower-facing or partner-facing use.

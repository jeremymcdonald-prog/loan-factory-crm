# Naming Convention

## Template IDs

Every template uses a stable `EMT-*` ID.

- Current range: `EMT-001` through `EMT-135`
- Specialty template range: `EMT-066` through `EMT-135`
- Do not reuse retired IDs.
- Do not rename IDs after release.

## Headings

Template headings should follow this pattern:

```text
## EMT-000 Template Name
```

## YAML Metadata

Every sendable template should include YAML metadata before the heading. Preserve existing fields when editing templates.

## File Names

Use two-digit numbered file names for source template files and clear title-case names for documentation files.

## Search Names

Template names should use borrower or operations language, not internal shorthand, unless the shorthand is widely understood in mortgage operations.
